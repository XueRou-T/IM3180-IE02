# IM3180 Design & Innovation Project - Group IE02 - Development of a Fun and Engaging Game (B)

## Ghost of You
A 2D pixel-art, story-driven adventure game developed in Unity using C#. Players follow Jonathan as he uncovers his forgotten memories through exploration, interactive storytelling, puzzles, and minigames.

## Features:
- Exploration: Navigate different environments and interact with NPCs and objects.
- Dialogue System: Character conversations with speaker portraits and branching dialogue choices.
- Clue Collection & Journal: Discover clues and piece together the protagonist's forgotten past.
- Puzzle Mechanics: Solve interactive puzzles, including laptop security questions.
- Minigames: Participate in story-related minigames set in different environments.
- Multiple Endings: Player decisions determine the outcome of the story.
- Cutscenes: Story-driven cinematic sequences to reveal key narrative events.

## Built With:
- Unity
- C#
- Blender
- GitHub
